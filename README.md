# 백귀타로

백 귀신의 패로 보는 타로. 질문 하나를 넣으면 패를 흩고 세 장을 뽑아 인(因)·연(緣)·과(果)로 풀어준다.

## 지금 들어있는 것

- `index.html` — 화면과 풀이 엔진이 한 파일에 들어 있다. 서버도 데이터베이스도 필요 없다.
- `img/` — 제목 붓글씨, 첫 화면 배경, 무녀, 카드 뒷면, 카드 그림.

## 짜임새

| 화면 | 하는 일 |
| --- | --- |
| 첫 화면 | 질문을 받는다. 생년월일은 묻지 않는다. |
| 패 흩기 | 손으로 쓸어 패를 흩는다. 두세 번 왕복하면 넘어간다. |
| 패 뽑기 | 원형으로 도는 예순 장에서 세 장을 고른다. |
| 풀이 | 인·연까지 보여주고 과(果)는 봉인. 1,900원에 풀린다. |

## 패

- 갈래: 검(소드) · 잔(컵) · 전(펜타클) · 지(완드) + 대귀
- 겉은 타로, 속은 오행. 화면에는 오행을 드러내지 않고 시기 계산에만 쓴다.
- 뒤집혀 나온 패는 "깨어남"으로 보고 풀이가 한 단계 세진다.

## 풀이 엔진

1. 질문에서 주제를 가린다 (연애 · 금전 · 직장 · 사람 · 건강)
2. 세 장의 오행이 어디로 몰렸는지 세어 **시기**를 뽑는다
3. 뒤집힌 장수로 **확답**의 강도를 네 단계로 가른다
4. 가장 센 귀를 골라 **붙은 귀**로 지목하고, 왜 붙었는지와 **떼는 법**을 준다

## 아직 안 된 것

- 결제가 붙어 있지 않다. 봉인 해제를 누르면 그냥 열린다.
- 풀이 글이 미리 써둔 것이라 질문을 실제로 읽지는 않는다.
- 패가 열 장뿐이다. 백 장을 다 넣어야 한다.
- 배경음이 없다.

## 띄우는 법

파일을 그대로 올리면 된다. 깃허브 페이지든 다른 곳이든 `index.html`만 열리면 돌아간다.
