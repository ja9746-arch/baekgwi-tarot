# 백귀타로

백귀술사 **호연(狐煙)** 이 백 귀신의 패로 보는 타로. 질문 하나를 넣으면 열 장을 뽑아 인(因)·연(緣)·은(隱)·적(敵)·조(助)·심(心)·시(時)·귀(鬼)·부(符)·과(果)로 풀어준다.

## 들어있는 것

- `index.html` — 화면 전체와 뼈대 엔진. 서버 없이도 혼자 돈다.
- `api/reading.js` — 덮인 일곱 장을 호연의 말로 쓰는 서버 쪽 함수.
- `img/` — 붓글씨 제목, 배경, 호연 다섯 장면, 카드 뒷면.
- `img/baekgwi/` — 해동 백귀야행 백 장의 그림 (백귀사주와 같은 그림).

## 패 백 장

백귀사주의 해동 백귀야행 백 귀신을 그대로 쓴다. 다섯 군을 갈래로 얹었다.

| 군 | 갈래 | 장수 |
| --- | --- | --- |
| 사고 재액군 | 대귀 | 20 |
| 구설 관재군 | 검(소드) | 20 |
| 인연 파괴군 | 잔(컵) | 20 |
| 재물 포식군 | 전(펜타클) | 20 |
| 정신 잠식군 | 지(완드) | 20 |

오행은 갈래마다 목·화·토·금·수 네 장씩 고르게 박았다. 그래서 백 장 전체로도 오행마다 스무 장이고, 시기 계산이 한쪽으로 쏠리지 않는다.

## 풀이가 만들어지는 방식

뼈대와 살을 나눠 놓았다.

**뼈대는 화면 쪽 코드가 계산한다.** 질문에서 주제(연애·금전·직장·사람·건강·아이)와 묻는 꼴(언제·왜·어떻게·누구·될까)을 가려내고, 뽑힌 열 장의 오행이 어디로 몰렸는지, 어느 갈래가 많은지, 대귀가 몇 장인지, 뒤집힌 패가 몇 장인지를 세어 **갈리는 때**와 **확답**을 확정한다. 이 값은 누가 읽든 바뀌지 않는다.

**살은 모델이 붙인다.** `api/reading.js` 가 그 뼈대와 뽑힌 패를 그대로 넘기면서 "이 결론은 바꾸지 말고 이 사람 질문에 맞춰 풀어라"라고 시킨다. 그래서 말과 디테일은 매번 달라지되 결론은 흔들리지 않는다.

**서버가 없거나 끊기면** 화면 쪽에 미리 써둔 풀이로 그대로 이어진다. 손님은 끊긴 줄 모른다.

**무료 세 장은 모델을 쓰지 않는다.** 봉인을 풀어 결제한 뒤에만 서버를 부른다.

## 같은 물음은 같은 패로

타로는 뽑을 때마다 패가 달라지니, 같은 물음을 여러 번 던지면 답이 흔들린다. 그래서 한 번 물은 것은 기억해 둔다.

- 물음을 띄어쓰기·문장부호·끝말(요, 까요, 나요…)을 걷어 낸 뒤 두 글자씩 쪼개 견준다. 72% 넘게 겹치면 같은 물음으로 본다. "바람난 걸까요?"와 "바람 난 걸까?"는 같은 물음이다.
- 같은 물음이 30일 안에 다시 들어오면 새로 뽑지 않고, 그때 뽑은 패와 그때 쓴 풀이를 그대로 펼친다.
- 30일이 지나면 다시 뽑을 수 있다.
- 첫 화면의 "지난 물음 다시 보기"로 언제든 다시 열 수 있다. 새로고침해도 풀이가 날아가지 않는다.
- 기록은 손님의 기기(브라우저)에만 남는다. 기기를 바꾸면 따라가지 않는다. 결제를 붙일 때 주문 번호에 묶어 서버에도 남기면 된다.

## 풀이 구조

- 무료 세 장(因·緣·隱)도 서버가 붙어 있으면 호연이 직접 쓴다. 때와 확답은 말하지 않고, 덮인 일곱 장을 궁금하게 만들며 끝맺는다.
- 서버가 없으면 틀 문장으로 대신한다. 틀 문장도 물음 속 사람(남편·상사…), 때를 가리키는 말(요즘·작년…), 마음(불안·서운함…), 사정 마디를 뽑아 되짚는다.
- 확답은 여러 근거를 셈해 정한다: 果·助·敵·緣 자리가 뒤집혔는지, 끝자리에 대귀가 앉았는지, 물음의 갈래가 敵·助 어디에 섰는지, 끝자리 오행이 몰린 오행과 서로 살리는지 부딪히는지. 그 근거는 풀이 끝에 "확답의 근거"로 그대로 보여 준다.
- 주제는 낱말 수로 견줘 고른다(연애·금전·직장·사람·건강·아이). "A 아니면 B" 꼴의 물음은 둘 중 하나를 골라 준다.

## 화면

- 풀이 화면의 패판은 한 줄 열 칸으로 줄였다. 열린 패를 누르면 크게 볼 수 있다.
- 패가 뒤집힐 때마다 화면 가운데에 크게 뒤집혀 보인다.
- 봉인을 풀면 붉은 빛, 흔들림, 封 자가 하나씩 깨지는 연출이 나온다.
- 소리는 파일 없이 브라우저에서 바로 빚는다(낮은 울림, 바람, 방울). 오른쪽 위 音 단추로 끈다.
- "한 장으로 남기기"는 질문·열 장·때·확답을 세로 그림 한 장으로 만든다. 카톡 안에서는 길게 눌러 저장하도록 안내하고, 다른 브라우저로 여는 단추를 띄운다.
- 카톡 미리보기 그림은 `img/og.jpg`. 주소는 `https://baekgwi-tarot.vercel.app/` 로 박아 두었으니 도메인을 바꾸면 `index.html` 머리의 og 주소도 바꿔야 한다. 베르셀 인증을 켜 두면 카톡이 그림을 못 가져간다.

## 띄우는 법

### 깃허브 페이지 (서버 없이)
`main` 브랜치 루트를 그대로 올리면 된다. 풀이는 미리 써둔 글로 나온다.

### 베르셀 (서버까지)
저장소를 가져와 올리기만 하면 된다. 설정도 열쇠도 건드릴 것이 없다.

모델은 백귀사주와 같은 통로(베르셀 AI 게이트웨이)를 쓴다. 베르셀 안에서 돌 때는
`VERCEL_OIDC_TOKEN` 이 자동으로 붙으므로 열쇠를 따로 넣지 않아도 된다.

필요할 때만 넣는 것들:

| 이름 | 쓰임 |
| --- | --- |
| `AI_GATEWAY_API_KEY` | 베르셀 밖에서 돌리거나 통로를 직접 지정할 때 |
| `ANTHROPIC_API_KEY` | 게이트웨이를 안 쓰고 앤트로픽을 직접 부를 때 |
| `BAEKGWI_MODEL` | 모델 교체. 기본은 `anthropic/claude-haiku-4.5` |

열쇠는 반드시 서버 쪽 환경변수에 둔다. 화면 쪽 파일에 적으면 하루면 털린다.

## 아직 안 된 것

- **결제가 붙어 있지 않다.** 지금은 봉인 해제를 누르면 그냥 열린다. 결제를 붙이기 전에는 `api/reading.js` 를 공개된 주소에 두지 말 것. 누구나 공짜로 부를 수 있다.
- 통신판매업 신고번호가 비어 있다. 신고 뒤 `index.html` 의 이용안내에 채워 넣어야 한다.
- 배경음이 없다.
