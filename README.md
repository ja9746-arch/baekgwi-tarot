# 백귀타로

백귀술사 **호연(狐煙)** 이 백 귀신의 패로 보는 타로. 질문 하나를 넣으면 열 장을 뽑아 인(因)·연(緣)·은(隱)·적(敵)·조(助)·심(心)·시(時)·귀(鬼)·부(符)·과(果)로 풀어준다.

## 들어있는 것

- `index.html` — 화면 전체와 뼈대 엔진. 서버 없이도 혼자 돈다.
- `api/reading.js` — 덮인 일곱 장을 호연의 말로 쓰는 서버 쪽 함수.
- `img/` — 붓글씨 제목, 배경, 호연 다섯 장면, 카드 뒷면과 카드 그림.

## 풀이가 만들어지는 방식

뼈대와 살을 나눠 놓았다.

**뼈대는 화면 쪽 코드가 계산한다.** 질문에서 주제(연애·금전·직장·사람·건강·아이)와 묻는 꼴(언제·왜·어떻게·누구·될까)을 가려내고, 뽑힌 열 장의 오행이 어디로 몰렸는지, 어느 갈래가 많은지, 대귀가 몇 장인지, 뒤집힌 패가 몇 장인지를 세어 **갈리는 때**와 **확답**을 확정한다. 이 값은 누가 읽든 바뀌지 않는다.

**살은 모델이 붙인다.** `api/reading.js` 가 그 뼈대와 뽑힌 패를 그대로 넘기면서 "이 결론은 바꾸지 말고 이 사람 질문에 맞춰 풀어라"라고 시킨다. 그래서 말과 디테일은 매번 달라지되 결론은 흔들리지 않는다.

**서버가 없거나 끊기면** 화면 쪽에 미리 써둔 풀이로 그대로 이어진다. 손님은 끊긴 줄 모른다.

**무료 세 장은 모델을 쓰지 않는다.** 봉인을 풀어 결제한 뒤에만 서버를 부른다.

## 띄우는 법

### 깃허브 페이지 (서버 없이)
`main` 브랜치 루트를 그대로 올리면 된다. 풀이는 미리 써둔 글로 나온다.

### 베르셀 (서버까지)
저장소를 가져와 올리기만 하면 된다. 설정도 열쇠도 건드릴 것이 없다.

모델은 백귀사주와 같은 통로(베르셀 AI 게이트웨이)를 쓴다. 베르셀 안에서 돌 때는
`VERCEL_OIDC_TOKEN` 이 자동으로 붙으므로 열쇠를 따로 넣지 않아도 된다.

필요할 때만 넣는 것들:

| 이름 | 쓰임 |
| --- | --- |
| `AI_GATEWAY_API_KEY` | 베르셀 밖에서 돌리거나 통로를 직접 지정할 때 |
| `ANTHROPIC_API_KEY` | 게이트웨이를 안 쓰고 앤트로픽을 직접 부를 때 |
| `BAEKGWI_MODEL` | 모델 교체. 기본은 `anthropic/claude-haiku-4.5` |

열쇠는 반드시 서버 쪽 환경변수에 둔다. 화면 쪽 파일에 적으면 하루면 털린다.

## 아직 안 된 것

- **결제가 붙어 있지 않다.** 지금은 봉인 해제를 누르면 그냥 열린다. 결제를 붙이기 전에는 `api/reading.js` 를 공개된 주소에 두지 말 것. 누구나 공짜로 부를 수 있다.
- 통신판매업 신고번호가 비어 있다. 신고 뒤 `index.html` 의 이용안내에 채워 넣어야 한다.
- 패가 스무 장뿐이다. 백 장을 다 넣어야 한다.
- 배경음이 없다.
